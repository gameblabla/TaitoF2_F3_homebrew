Homebrew source code by Charles Doty for Taito arcade boards (F2 and F3)
=========================================================================

For Taito F2 and Taito F3 arcade boards.

This includes a few homebrew demos along with source code to make your own game for these arcade boards.

This used to be on http://arcadedev.emuvibes.com (as f3demo.zip and f2demo.zip) but it's now gone.

Besides the NAOMI hardware (with KallistiOS does support) and the Voodoo based arcade boards (DOS),
the F3 is the most powerful arcade pcb you can target.
